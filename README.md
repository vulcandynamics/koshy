This project is about a four wheel drive robot which has an ultrasonic sensor which will scan the surroundings for obstacles and locate them and will perform movements in such a way to avoid the obstacle

The main working principle would be classified into the following:
 1. Detection: First the ultrasonic sensor will scan the surroundings for obstructions.
 2. Computing: Now if it finds an obstruction it will calculate the distance and the angle between the vehicle and the obstruction 
 3. Execution: now with some harcoded threshold distance and angle it will move in such a manner to avoid the obstacle
